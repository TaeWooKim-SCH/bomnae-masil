# frontend/ — R1(우영찬) 영역 규칙

- **화면 동작의 진실은 `docs/25-screens.md`다.** 여기 정의된 요소·상태·문구를 그대로 구현하고, 없는 동작은 임의로 만들지 말고 이슈에 질문을 남겨라
- **목 우선 개발**: `VITE_USE_MOCK=true`로 `src/mocks/`의 목 JSON을 쓰고, 실서버 전환은 `src/api/client.ts`의 스위치 한 곳에서만. 화면 컴포넌트가 목의 존재를 알면 안 된다
- **서버가 준 값(점수·버스·D-day·예산 합계)은 표시만** — 화면에서 재계산·보정 금지
- 모바일 375px 우선. 시민 화면에 "저유입·취약" 같은 낙인어 노출 금지 (긍정 언어 원칙)
- "13시 42분 버스" 같은 분 단위 시각표·실시간 도착 표기 금지 — "약 N분 간격"만
- localStorage 키는 `session_id`·`active_quest_id` 둘뿐. "세션 없음" 응답 시 키 폐기 + 첫 방문 모달

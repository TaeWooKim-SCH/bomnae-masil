# pipeline/ — R3(최우혁) 영역 규칙

- **데이터 목록·수집 규칙의 진실은 `docs/15-data.md`다** (포털 점검 중엔 4-1 대체 수집처 사용)
- 스냅샷 원칙: 원본 파일은 `snapshots/`(.gitignore — 팀 드라이브 공유), 본선장에서 새로 받지 않는다
- 전국 데이터는 **적재 전에 춘천 필터** (DB 무료 용량 500MB 한도)
- 좌표는 전부 EPSG:4326으로 통일(인허가는 5174→4326 변환), 좌표 실패 행은 제외하되 드롭 건수를 15-data에 기록
- "측정 이력 없음" 가게는 저유입 확정이 아니라 추정 후보(중간 점수) — 편향 방지 원칙
- 접근성 점수표가 무환승·경로·소요시간의 **단일 원천** — 여기서 계산한 것을 다른 코드가 조회한다
- 데모 가게 5곳의 verify_code 확정·인쇄 후에는 merchants 재적재 금지(ID 동결)

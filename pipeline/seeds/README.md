# seeds/ — 수기 씨드 데이터

`always_open_activities.csv` — 상시형 활동 씨드 (#49). 파이프라인이 다른 소스와 동일하게 `activities`로 적재하되 지오코딩·온라인 필터는 건너뜀(좌표 직접 기입).

## 채우는 법 (씨드당 ~3분)
1. **좌표**: 카카오맵에서 장소 검색 → 우클릭 "여기 주소·좌표" → lat/lng 복사 (필수 — 비면 적재 제외됨)
2. **운영시간·휴관일 검증**: 기관 홈페이지·네이버플레이스에서 확인 — **8/1은 토요일**, 데모에 걸리는 휴관 없는지 필수 확인 (박물관·미술관류는 월요 휴관이 일반적)
3. **interest_tags는 칩 7종만** 사용 (운동·건강/문화·공연/공예·만들기/사진·미디어/요리·먹거리/학습·어학/자연·나들이), 세미콜론 구분

## 장소 선정 원칙
- **도보 반경에 가게가 있는 곳 우선** — 미션이 붙어야 100P 카드가 됨 (원도심 육림고개·약사천·도서관 계열이 유리)
- 데모 가게 5곳(#47)과 동선이 겹치는 장소 1~2개 포함
- 축제가 8/1 진행 중이면 당일형으로 1건 추가 (#49 코멘트)

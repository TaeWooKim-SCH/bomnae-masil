# 조각지도 프로토타입 생성 프롬프트 (클로드 디자인 세션에 그대로 붙여넣기)

> 용도: 보관함(기록) 화면에 추가되는 **"봄내 조각지도"** 섹션의 프로토타입 생성 (#100).
> 아래 구분선 안쪽 전체를 복사해서 사용. 생성 결과는 단독 HTML 파일로 받는다.

---

춘천 지역 활동×골목상권 매칭 웹서비스 "봄내마실"의 보관함 화면에 들어갈 **"봄내 조각지도" 섹션** 프로토타입을 만들어줘. 단일 HTML 파일(단독 실행, 라이브러리 CDN 금지), 모바일 375px 기준.

## 유지할 것 (기존 프로토타입과 동일)
- 디자인 토큰: 주색 #0E87C4(파랑), 짙은 배경 #0B3A52, 본문 #1C262B, 보조 #5E6B72~#93A0A8, 라인 #CBD8DF, 서체 Pretendard(폴백 -apple-system)
- 말투: 존댓말. 낙인·부정 표현 금지

## 조각지도 섹션 구성 (위→아래)
1. 제목 "봄내 조각지도" + 진행 요약 **"8 / 14 동"** (분모 = 활동이 있는 동만)
2. **춘천 행정동 지도** — 실제 지리 정확도는 불필요, 행정동 경계를 단순화한 퍼즐 느낌의 폴리곤(SVG)으로 25개 동을 그려줘. 상태 3종이 한눈에 구분되게:
   - **채움** (완주한 동, 8개): 주색 #0E87C4 계열로 칠해짐 + 동 이름 흰색
   - **미채움** (활동은 있는데 아직 안 간 동, 6개): 옅은 하늘/회백 톤 + 가는 테두리
   - **잠금** (아직 활동이 없는 동, 11개): 회색 + 빗금 또는 자물쇠 아이콘. ⚠ "잠김/불가" 같은 부정 표현 대신 탭하면 **"아직 준비 중인 동네예요"** 툴팁
3. 마일스톤 칭호 칩 3개: 「동네 수집가」(5동, 달성됨) · 「골목 탐험가」(10동, 진행 중 8/10) · 「봄내 완주」(수집판 전부, 잠김 상태 표기)
4. 최근 획득 연출 데모: "석사동 조각을 얻었어요!" 토스트 + 해당 폴리곤이 채워지는 간단한 애니메이션 (버튼으로 재생 가능하게)

## 데모 데이터
- 채움 8: 석사동, 효자1동, 조운동, 소양동, 퇴계동, 신북읍, 신동면, 서면
- 미채움 6: 동면, 사북면, 후평1동, 강남동, 교동, 근화동
- 잠금 11: 나머지 동 (동산면, 남면, 남산면 등)

## 넣지 말 것
- 실제 카카오맵·외부 지도 타일 (프로토타입은 SVG 약식 폴리곤)
- 포인트 차감·구매 요소 (조각은 완주로만 획득)
- 랜덤 뽑기·가챠 연출 (조각 = 내가 실제로 간 동)

# 프로토타입 v3 생성 프롬프트 (클로드 디자인 세션에 그대로 붙여넣기)

> 용도: 변경된 기획에 맞춰 **추천(퀘스트 탭) 카드**와 **상세 페이지**를 수정한 v3 생성.
> 아래 구분선 안쪽 전체를 복사해서 사용.

---

춘천 지역 활동×골목상권 매칭 웹서비스 "봄내마실"의 프로토타입을 만들어줘. 기존 v2가 있고 전체 룩은 유지하되, 아래 스펙대로 **추천 화면 카드와 상세 페이지를 수정**하는 게 목적이야. 단일 HTML 파일(단독 실행, 라이브러리 CDN 없이)로 만들어줘. 모바일 375px 기준.

## 유지할 것 (v2와 동일)
- 디자인 토큰: 주색 #0E87C4(파랑), 짙은 배경 #0B3A52, 본문 #1C262B, 보조 #5E6B72~#93A0A8, 라인 #CBD8DF, 서체 Pretendard(폴백 -apple-system)
- 화면 흐름: 홈(입력) → 추천(카드) → 상세 → 인증 → 기록. 상단에 포인트 잔액 표시
- 말투: 존댓말. "저유입·취약" 같은 낙인 표현은 시민 화면에 금지 — "숨은 가게", "새로 만나는 가게"로

## 추천 화면 — 퀘스트 카드 (핵심 수정)
카드 1장 구성 (위→아래):
1. 활동명 + 활동 종류 라벨(당일형/신청형/상시형) + 시간 요약
   - 신청형이면 **"개강 D-n" 뱃지** (⚠ "마감"이라는 단어 금지)
   - 상시형이면 "운영시간 내 자유 이용" 표기
2. 가게 미션 한 줄 (예: "전시 보고 나와서, 필름 감성 그대로 따뜻한 한 잔 어때요? — 육림고개 ○○카페")
3. 버스 한 줄: **"300번 · 7개 정거장 · 약 25분"** + **"환승 없음" 배지**
   - ⚠ 절대 금지: "지금 N분 후 도착"(실시간), "약 N분 간격"(배차간격), "13:42 버스"(시각표) — 어떤 형태의 시간표·도착 정보도 넣지 마
   - 출발 정류장을 사용자가 안 골랐으면 작은 글씨로 "석사동 현진아파트 정류장 기준"
4. 예산 합계: "약 20,000원 (버스 왕복 포함)"
5. 점수 구성 미리보기: 5지표 미니 막대 — 상권 기여(최대 30)/관심사(25)/접근성(20)/시간(15)/예산(10)
6. 우상단에 "최대 100P" (가게 없는 카드는 "최대 60P")

**가게 없는 퀘스트 카드**: 미션 줄 자리에 "이번엔 활동만 즐겨요 — 기록으로 완주 (+60P)", 예산은 활동비+버스만.

카드 3장 아래 **"다른 추천 보기" 버튼(무료)**: 누르면 4~6위 카드가 아래에 **추가로 펼쳐짐**(기존 3장 교체 아님). 한 번 쓰면 버튼 숨김 + "조건을 바꿔 다시 받아보세요".

## 상세 페이지 (핵심 수정)
1. 지도 영역(플레이스홀더 사각형으로 대체 가능): 마커 3종 — 활동지(주색)·가게(주황)·승하차 정류장(회색, **경험 장소가 아니라는 게 색·아이콘으로 구분되게**) + 경로선
2. 활동 블록: 상세 정보. 신청형이면 "오늘 할 일: 신청하기 → 장소 미리 가보기 → 근처 가게 미션" 안내
3. 버스 블록: **"300번 · 7개 정거장 · 약 25분"** 고정 표기 (위 금지 목록 동일)
4. 미션 블록: 문안 + 인증 방법 안내(QR 스캔 / 4자리 코드 / 영수증)
5. 예산 블록: 합계
6. 하단 고정 CTA **"퀘스트 시작"** — 누르면 진행 중 퀘스트가 있을 때의 확인 모달("진행 중인 퀘스트가 있어요. 새로 시작하면 기존 퀘스트는 중단돼요") 데모도 포함
7. **이미 시작한 퀘스트로 재진입한 상태**도 토글로 시연 가능하게: 시작 버튼 대신 "인증하러 가기" / "기록 쓰기" 버튼 2개

## 데모 데이터 (실데이터 기반 — 이 3장을 기본 노출)
1. 당일형·가게 있음: 「무민가족의 모험전」 전시, 춘천문화예술회관, 오늘 10:00–18:00, 8,000원 / 미션: 육림고개 카페 / 버스 300번 · 7개 정거장 · 약 25분 / 최대 100P
2. 상시형·가게 있음: 「춘천시립도서관에서 느긋한 오후」, 운영시간 내 자유 이용, 무료 / 미션: 근처 소품숍 / 버스 64번 · 5개 정거장 · 약 18분 / 최대 100P
3. 당일형·가게 없음: 「로비전시 《여전히 춘천》」, 춘천문화예술회관, 무료 / "이번엔 활동만 즐겨요 — 기록으로 완주 (+60P)" / 버스 9번 · 4개 정거장 · 약 12분 / 최대 60P
"다른 추천 보기"용 4~6위도 같은 규칙으로 2~3장 만들어줘 (그중 1장은 신청형 "개강 D-5" 뱃지 예시).

## 위계 (중요)
**동작의 진실은 `docs/25-screens.md`다.** 프로토타입과 정의서가 다르면 정의서가 우선한다.

## 알려진 편차
1. **대시보드 화면 없음** — 화면 6번(#33)은 프로토타입 범위 밖. 25-screens 6장 정의로 별도 구현 (디자인 토큰만 공통 사용)
2. **[조각지도] "춘천사랑상품권 5,000원" 리워드 문구** — 기획에 없음(협약 불필요 원칙 위반). 구현은 「봄내 완주」 칭호로 교체, 상품권은 운영 로드맵 문구로만
3. **[조각지도] "잠김 · 준비 중" 라벨** — 구현은 부정 표현 빼고 "준비 중인 동네"로
4. **[조각지도] 리워드 기준 불일치** — 데모 도우미 "10개" vs 모달 "14조각". 구현 기준: 마일스톤 칭호 5동·10동 + 전판(available 전체) 완성
5. **[조각지도] 마일스톤 칭호 칩 3종 미노출** — 조건부 뱃지("골목 탐험가")만 존재. 구현은 칩 3종 상시 노출(#100 단계 4)
6. **[조각지도] 외곽 읍면 전부 잠금 고정** — 정적 데모 표현. 실구현은 zone_map 기반: 활동 있는 외곽 동(신북읍·서면·신동면 등)은 잠금이 아니라 수집 대상
